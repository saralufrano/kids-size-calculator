# kids-size-calculator

Tiny clothes + shoe size calculator, with Capacitor ready for iOS and Android.

## Mobile setup

```bash
npm install
npm run cap:add:ios
npm run cap:add:android
```

After the native projects exist:

```bash
npm run cap:open:ios
npm run cap:open:android
```

`npm run cap:sync` copies the latest `index.html` into the native apps before opening them.
